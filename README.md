# AuraBrain Pro

3B parameter LLM with tool-calling. Q4_K_M quantised. Runs locally via Ollama.

## Quick Start

```bash
# 1. Install Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 2. Run AuraBrain Pro
ollama run aurabrain-pro

# 3. Or install from GGUF (download from Releases)
ollama create aurabrain-pro -f Modelfile
```
