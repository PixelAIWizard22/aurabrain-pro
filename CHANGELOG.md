## [6.0.0] - 2025-05-15

### Added
- Q4_K_M quantised model (1.9GB download)
- Tool-calling support (function use)
- Brain-enhanced system prompt (CoVe verification, SAVeR, self-correction)
- Brain Search integration (Wikipedia + Wikidata + brain atoms)
- Brain Notepad (save facts/lessons/decisions as brain atoms)
- 3-brain sync support (Agency, Hermes, Pi)
- Configurable inference parameters (temperature, top_p, context length)
- Ollama Modelfile for one-command install

### Model Family
- aurabrain-micro: 0.5B, 397MB (phones, IoT)
- aurabrain-light: 1.5B, 986MB (tablets)
- aurabrain-pro: 3B, 1.9GB (full tool-calling + brain)

### Base Model
- Qwen2-1.5B-Instruct (Qwen RESEARCH LICENSE)
